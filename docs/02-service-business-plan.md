# AI 수익화 사업 기획서 — 우리는 무엇으로 돈을 벌 것인가

> 작성일: 2026-07-21. 근거 데이터는 `01-ai-monetization-research.md` 참조.
> 전제: 소규모 팀(1~3인), 소자본(월 고정비 20만 원 내외로 시작), 한국 기반.

---

## 1. 전략 원칙 (조사에서 도출)

1. **광고수익형 양산 콘텐츠는 하지 않는다.** 유튜브 2025.7 비진정성 정책 + 애드센스 RPM 붕괴로 구조적으로 막힌 길. 콘텐츠는 수익원이 아니라 **모객 채널**로만 쓴다.
2. **"채팅"이 아니라 "실행"을 판다.** 특정 업종의 반복 업무를 대신 끝내주는 서비스에만 지갑이 열린다 (버티컬 AI NRR 130%+, 래퍼 90% 실패).
3. **국내 = 레퍼런스·B2B·현금흐름 / 글로벌 = 구독 매출.** 라이너·스노우가 검증한 이중 구조. 글로벌 결제는 Paddle(MoR)로 해외 법인 없이 처리.
4. **포트폴리오 + 빠른 손절.** MVP 4~8주 내 출시, 6개월 $500 MRR 미만이면 정리하고 다음 제품. 첫 제품 12개월 목표는 월 500만 원(≈$4K MRR, 성공 중앙값).
5. **유통을 제품과 동시에 시작.** 빌드인퍼블릭(X/스레드) + SEO + 숏폼 중 2개 이상.

---

## 2. 후보 사업 3개 비교

| | A. 이커머스 셀러용 AI 스튜디오 | B. 소상공인 AI 응대 에이전트 | C. AI 교육/커뮤니티 |
|---|---|---|---|
| 내용 | 상품 사진 → AI 모델 착용컷·상세페이지·광고소재 자동 생성 (스마트스토어/쿠팡 셀러 대상) | 카카오톡 채널·전화(음성 AI) 예약/문의 자동 응대 구축 + 월 관리 (병원·학원·미용실·식당) | AI 활용법 강의·전자책·유료 커뮤니티 |
| 검증 근거 | 크몽 AI 카테고리 1위 상품이 'AI 모델'. 스노우 월매출 14배 사례. 촬영비 1/10 소구 | 음성 AI 최고 성장 세그먼트(AI 리셉셔니스트). 카카오 챗봇 절감 효과 1,414억. 해외 AAA 리테이너 모델 | 지피터스 월 10~12만 멤버십, Skool 상위 월 $335K |
| 수익 모델 | 구독(월 3~10만 원) + 크레딧 | 구축비 100~300만 원 + 월 리테이너 20~50만 원 | 강의 단건 + 월 구독 |
| 초기 매출 속도 | 중간 (셀프서브, 모객 필요) | **빠름** (영업만 되면 첫 달부터 건당 매출) | 느림 (오디언스 선행 필요) |
| 확장성 | **높음** (글로벌 확장 가능) | 중간 (사람 손 타는 대행 → 제품화 필요) | 낮음 (창업자 시간에 종속) |
| 리스크 | 네이버/카카오가 기능 내장할 가능성 | 커머디티화 (n8n 대행 경쟁 심화) | 오디언스 없으면 시작 불가 |

## 3. 권고: "B로 현금흐름 → A로 제품화" 투트랙

**1단계 (0~3개월): B — 소상공인 AI 응대 에이전트 대행**으로 시작한다.
- 이유: 영업 1건이면 즉시 매출(구축비+리테이너). 4~8주 내 첫 매출이라는 정상 궤도를 가장 확실히 밟는 길이고, 고객 현장에서 도메인 지식(어떤 업무가 진짜 아픈지)이 쌓인다. 이 도메인 지식이 2단계 제품의 해자가 된다.
- 스택: 카카오톡 채널 + 채널톡/자체 웹훅 + Claude API(Haiku 라우팅·프롬프트 캐싱) + n8n 셀프호스팅. 음성은 국내 통화 연동 가능한 보이스 API로 2차 확장.
- 목표: 3개월 내 유료 고객 5곳, 월 리테이너 합계 150만 원+.

**2단계 (3~9개월): 대행에서 반복 패턴을 추출해 A 또는 B의 셀프서브 SaaS로 제품화.**
- 대행 고객 10곳이면 어떤 업종·어떤 워크플로가 반복되는지 데이터가 나온다. 그 최다 반복 패턴 하나만 떼어 셀프서브 제품(월 3~10만 원 구독)으로 만든다.
- 결제: 국내 토스페이먼츠, 글로벌 Paddle. 목표: 12개월 차 MRR 500만 원.

**3단계 (상시 병행): 콘텐츠는 모객용으로만.**
- 유튜브/스레드에 "AI로 사장님 업무 자동화하는 과정"을 기록(빌드인퍼블릭). 이것이 영업 리드 + 채용 + 신뢰를 만든다. 조코딩·서희찬·지피터스 전원이 이 구조.
- 오디언스가 쌓이면 전자책·강의(C)를 부수입으로 얹는다 — 주력이 아니라 파생상품.

## 4. 실행 로드맵 (첫 90일)

| 주차 | 할 일 |
|---|---|
| 1~2주 | 타깃 업종 1개 확정(권장: 예약 기반 업종 — 미용실/학원/병원). 해당 업종 사장 10명 인터뷰로 최다 반복 문의 파악 |
| 3~4주 | 카톡 채널 챗봇 MVP 구축(예약 문의·위치·가격 FAQ 자동 응대 + 사람 이관). 지인 매장 1곳 무료 설치 → 사례화 |
| 5~8주 | 사례 기반 영업(네이버 플레이스 리뷰 많은 매장 콜드 아웃리치 + 소상공인 커뮤니티). **첫 유료 계약** (구축 100만 + 월 30만) |
| 5~8주 병행 | 스레드/유튜브에 구축 과정 주 2회 기록 시작 |
| 9~12주 | 고객 5곳 도달. 응대 로그에서 반복 패턴 분석 → 2단계 제품 스펙 초안 |

## 5. 손익 가늠 (보수적)

- **고정비**: 서버·툴 월 15~20만 원 + LLM API 변동비(고객당 월 1~3만 원 수준, 캐싱·Haiku 라우팅 적용 시).
- **6개월 차**: 고객 8곳 × 리테이너 평균 30만 = 월 240만 + 구축비 스팟 → 월 300만 안팎.
- **12개월 차**: 대행 유지 + SaaS MRR 200~300만 = **월 500~600만 원** (마이크로 SaaS 성공 중앙값 수준).
- 손절 규칙: 6개월 차에 월 매출 100만 미만이면 업종 또는 모델 피벗.

## 6. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 카카오/네이버가 동일 기능 무료 내장 | 플랫폼 기능이 아니라 "업종 특화 운영 노하우 + 사람 이관 + 관리"를 판다. 단일 플랫폼 종속 회피(카톡+전화+웹챗) |
| n8n 대행 경쟁 심화(커머디티화) | 대행은 입구일 뿐. 로그 데이터 → 셀프서브 제품화로 상향 이동 |
| LLM API 비용 잠식 | 크레딧제 과금 + 모델 라우팅 + 프롬프트 캐싱. 원가율 30% 상한 관리 |
| AI기본법(2026.1) 표시 의무 | 응대 시작 시 AI임을 고지(신뢰에도 유리) |
| 1인 운영 번아웃 | 구축 템플릿화·온보딩 자동화. 고객 10곳 넘으면 CS 파트타임 채용 |

## 7. 하지 않을 것 (명시적 제외)

- 양산형 AI 유튜브/블로그로 광고수익 노리기 (정책상 봉쇄됨)
- 범용 챗봇·범용 이미지 생성 앱 (90% 실패 구간)
- 오디언스 없이 강의/전자책부터 시작 (순서가 반대)
- 첫 제품부터 대규모 개발 (4~8주 내 출시 불가한 스코프는 자름)
