## 1. 창립 고객 제안 메시지 (콜드 아웃리치)

> 발송 원칙: 50곳 무작위 X. 가능성 높은 10곳을 골라 **그 업체 제품을 실제로 보고** 맞춤 문장 2줄을 넣는다.

```
[대표님 성함] 대표님, 안녕하세요.
가구네닷컴 [내 이름]입니다. ([관계 한 줄: 예 - 지난달 ○○ 거래 / △△ 전시회에서 인사드렸던])

[업체명]의 [구체 제품명]을 보다가 연락드립니다.
제품은 정말 좋은데, [맞춤 지적 1줄: 예 - 상세페이지 사진이 실물 매력을 다 못 담고 있다고 느꼈습니다 /
온라인 채널에서 검색해도 콘텐츠가 거의 없더라고요].

저희는 자사 브랜드 갈롱을 운영하며 AI로 촬영 없이 판매 콘텐츠를 만드는 시스템을 만들었고,
이번에 가구회사 3곳만 창립 고객으로 모십니다.

제품 사진 몇 장만 보내주시면:
- 한국 아파트·호텔형 공간 연출 이미지 12장
- 메타 광고용 이미지 6장 + 숏폼 광고 영상 3개
- 상세페이지 전체 기획안 + 광고 카피 20개
- 네이버 블로그 1건 + 인스타 3건 + 고객 FAQ
- 30일 콘텐츠 운영표
까지 신제품 1개를 '온라인에서 팔 수 있는 상태'로 만들어 드립니다.

창립 고객 조건: 제품 1개 99만원 (정상가 249만원 예정)
대신 결과물 사례 공개와 전후 데이터 제공에 동의해 주시면 됩니다.

갈롱 [제품명]으로 만든 실제 전후 사례 먼저 보내드릴까요?
```

**후속(3일 무응답 시)**: 사례 이미지 2~3장을 첨부하며 "부담 없이 보시라고 저희 갈롱 제품으로 만든 결과만 보내드립니다. 필요하실 때 연락 주세요." — 1회만.

## 2. 상담 질문지 (신청폼 문항)

> 구글폼/네이버폼으로 제작. 상담 전화보다 먼저 발송한다.

1. 회사명 / 담당자 성함·연락처
2. 이번에 콘텐츠가 필요한 제품은 무엇인가요? (제품명, 카테고리)
3. 이 제품을 주로 누가 구매하나요? (예: 신혼부부, 카페 사장님, 30~40대 아파트 거주)
4. 현재 판매 채널은 어디인가요? (자사몰 / 스마트스토어 / 오늘의집 / 쿠팡 / 오프라인·B2B / 준비 중)
5. 지금 가장 큰 고민은 무엇인가요? (사진 품질 / 광고 성과 / 상세페이지 / 검색 노출 / 문의 응대 / 기타)
6. 원하는 이미지 분위기가 있나요? (예: 밝은 아파트 / 호텔 럭셔리 / 미니멀 / 참고 브랜드 링크)
7. 비교되는 경쟁 브랜드·제품이 있다면 알려주세요.
8. 월 광고비는 어느 정도 쓰고 계신가요? (없음 / 100만 미만 / 100~500만 / 500만 이상)
9. 꼭 필요한 결과물을 골라주세요. (공간 이미지 / 광고 영상 / 상세페이지 / 블로그 / FAQ·CS / 전부)
10. 출시(또는 콘텐츠 적용) 목표일이 언제인가요?
11. 이번 건 예산 범위를 알려주세요. (~99만 / ~150만 / ~250만 / 협의)

**접수 후 AI 처리(대표는 확인·전송만)**: 답변 → ① 고객 문제 요약 ② 추천 패키지 ③ 제작 방향 ④ 예상 일정 ⑤ 필요 자료 목록 ⑥ 견적서 초안 자동 생성.

## 3. 견적·계약 전 안내문

```
[업체명] 견적 안내 — 가구네 AI 신제품 판매 패키지 (창립 고객)

■ 제공 범위 (제품 1개 기준)
  공간 연출 이미지 12장 / 광고 이미지 6장 / 숏폼 영상 3개 /
  상세페이지 기획안 / 광고 카피 20개 / 블로그 1건 / 인스타 3건 /
  FAQ·CS 답변 / 광고 테스트 기획안 / 30일 콘텐츠 운영표

■ 금액: 990,000원 (부가세 별도)  ※ 창립 고객 3개사 한정, 정상가 2,490,000원
■ 일정: 자료 수령일로부터 [10]영업일 내 1차 납품
■ 수정: 1차 납품 후 수정 1회 포함 (제품 사실 오류는 횟수 무관 즉시 수정)
■ 창립 고객 조건: 결과물 사례 공개 동의 / 적용 전후 데이터 공유 / 후기 1건
■ 진행 방식: 계약금 50% 입금 → 제작 착수 → 납품 → 잔금 50%
■ 자료 요청: 제품 원본 사진 5~10장(최대 해상도), 정확한 사이즈·소재·가격,
  제품 장점 메모, 경쟁 제품, 기존 상세페이지 링크, 고객 후기·문의 내용

■ 약속드리는 것: 제품 형태·색상·구조를 변형하지 않습니다.
  가구를 예쁘게 바꾸는 AI가 아니라, 실제 제품을 정확하게 보여주는 콘텐츠를 만듭니다.
  납품 전 전 항목 가구 전문 검수(검수표 공유 가능)를 거칩니다.

■ 유의: AI 생성 이미지는 관련 법령(AI기본법)에 따라 필요한 경우 AI 생성물임을 표시합니다.
```

## 4. AI 이미지·영상 검수표 (가구 특화)

> 납품 전 **전 컷 필수**. 하나라도 NO면 재생성. 검수자 서명 후 납품.

### A. 제품 원형 (변형 = 전량 폐기) — **최우선 항목: 방석·등쿠션 곡선**
- [ ] **방석(좌면)·등쿠션의 곡률·두께·모서리 라운드가 참조 사진과 일치** (이 곡선이 제품 디자인의 핵심 — 불일치 시 즉시 폐기)
- [ ] 다리 개수·위치·각도가 실물과 일치
- [ ] 프레임 굵기·형태 일치
- [ ] 상판 두께·모서리(라운드/직각) 일치
- [ ] 등받이·팔걸이 형태 일치
- [ ] 봉제선 위치·개수, 쿠션 분할·비율 일치
- [ ] 원단·마감 색상이 실물 기준 (모니터 캘리브레이션 기준 명시)
- [ ] 하드웨어(손잡이·다리 캡·스티치) 왜곡 없음
- [ ] 패턴·결(우드 그레인, 마블) 방향 자연스러움

### B. 공간·비율
- [ ] 제품 실측 사이즈 대비 공간 비율 정확 (1100 식탁이 1400처럼 보이지 않는가)
- [ ] 바닥 접지·그림자 자연스러움 (떠 보이지 않는가)
- [ ] 반사·질감이 소재와 일치 (세라믹/포세린/원목/패브릭)
- [ ] 주변 소품이 제품보다 시선을 뺏지 않음
- [ ] 한국 주거 현실성 (창호·바닥재·몰딩이 어색하지 않은가)

### C. 사실 표현 (법적 리스크)
- [ ] 존재하지 않는 기능(수납·확장·회전 등) 연출 없음
- [ ] 과장된 내구성·안전성 암시 없음 (예: 아이가 뛰는 장면)
- [ ] 소비자가 구성품으로 오해할 소품 없음 (의자 미포함인데 세트처럼 보임 등)
- [ ] 실사 혼동 우려 시 AI 생성 표시 처리
- [ ] 카피의 수치·소재 표기가 고객 제공 스펙과 일치

### D. 영상 추가
- [ ] 3초 안에 제품 등장
- [ ] 모션 중 제품 형태 붕괴 프레임 없음 (프레임 단위 확인)
- [ ] 자막 오탈자·금지 표현(최고/1위 등 근거 없는 최상급) 없음

## 6. 결과 보고서 양식 (납품 시 + 구독 전환용)

1. **요약 (1페이지)**: 제작물 목록 / 기존 대비 절감(비용·기간) / 즉시 실행 권고 3가지
2. **성과 지표**: §5 표 + 광고 테스트 결과 (소재별 CTR·CPM 비교)
3. **발견한 것**: 고객 문의·후기 분석에서 나온 구매 결정 요인 / 망설임 이유
4. **다음 달 제안**: 이번 결과 기반 개선 소재 방향 + 추가 제작 대상 상품
5. **구독 전환 제안 문구**:
   ```
   이번에는 제품 1개를 진행했지만, 광고 소재는 한 번 만들고 끝나는 게 아니라
   성과 데이터를 보고 매달 개선해야 효과가 유지됩니다.
   월 구독(첫 고객 190만원/월)으로 전환하시면 매월 [4]개 상품의
   콘텐츠 제작 + 성과 분석 + 소재 개선을 반복해 드립니다.
   ```
