## 2. 포지셔닝 (스펙 확정 전 가설 — 확정 후 1개 선택)

- 가설 A **"거실의 두 번째 자리"**: 소파는 있는데 내 자리가 없는 집. 포제 = 나만의 라운지 체어 자리. (타깃: 30~40대 아파트, 재택근무·독서)
- 가설 B **"구름 한 조각"**: 갈롱소파 헤리티지 직결 — 50kg 고탄성 스펀지의 1인용 버전. (타깃: 갈롱소파 기존 고객·오늘의집 유입)
- 가설 C **"관리되는 라운지 소파"**: 교체형 커버 시스템이면 — "예쁜 라운지 체어는 많지만, 5년 쓸 수 있는 건 드뭅니다". (타깃: 아이·반려동물 가정)
