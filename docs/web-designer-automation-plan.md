## 2. ✅ 오늘 구축 완료 — 일일 업무보고 자동화

| 구성 요소 | 내용 |
|---|---|
| ✅ 일일 업무 보고 DB (노션, HQ 하위) | 날짜·담당·제출·완료율(%)·이슈·내일 계획 속성 + 본문 데일리 체크리스트(오전 루틴 / 상세페이지 / SNS / 온보딩 / 퇴근 전) |
| ☀️ 아침 브리핑 Routine (평일 08:57) | 오늘자 보고 페이지 자동 생성 → 상세페이지 SLA 임박·초과 건 + 오늘 캘린더 일정을 요약해 슬랙 전송 |
| 🌆 저녁 업무보고 Routine (평일 17:57) | 체크 완료/미완료·이슈·내일 계획 + 상세페이지 처리 현황을 집계해 대표에게 슬랙 업무보고 자동 전송. 미작성 시 "보고 미작성" 알림 |

**디자이너가 할 일은 하나뿐**: 하루 동안 노션 체크리스트를 체크하고, 퇴근 전 이슈·내일 계획을 적고 「제출」을 체크한다. 보고서 작성·전송은 자동.

> ⚠️ 슬랙 전송은 claude.ai에 Slack 커넥터 연결이 완료되면 활성화된다. 연결 전에는 대표 메일(ceo@galon.co.kr)로 대신 발송된다.

## 3. 적응기(입사 ~1개월) 권장 자동화

우선순위 순. ⭐=추천 도구, 난이도는 설정에 드는 노력 기준.

| # | 자동화 | 도구 | 난이도 | 기대 효과 |
|---|---|---|---|---|
| 1 | **상세페이지 요청 접수 즉시 알림** — 요청 DB에 새 건 등록 시 담당자·팀장에게 알림 | ⭐노션 DB 자동화(유료 플랜) 또는 Make | 하 | 구두 요청 누락 방지, SLA 시계가 접수 즉시 시작 |
| 2 | **SLA 임박·초과 알림** — 마감 D-1/초과 건 아침 자동 보고 | ⭐Claude Routine (구축 완료, 아침 브리핑에 포함) | — | SLA 준수율 90% 목표 직결 |
| 3 | **SNS 발행 슬롯 자동 생성** — 매주 월요일 통합 캘린더에 인스타 4회·블로그 2회 발행 슬롯을 자동 등록 | ⭐Claude Routine 추가(주 1회) 또는 노션 반복 템플릿 | 하 | "오늘 뭘 올리지" 대신 "이 슬롯을 채우자"로 사고 전환 → 발행 빈도 유지 |
| 4 | **재가공 후보 자동 판정 보조** — 주 1회 인스타 저장수·문의 발생을 기록하면 평균 1.5배 기준으로 🔥 후보 리스트 자동 산출 | Claude Routine(월요일) + 콘텐츠 아이디어 뱅크 DB | 중 | 월요일 체크인 준비 자동화, 원소스 멀티유즈 규칙 실행력 확보 |
| 5 | **주간 보고 초안 자동 생성** — 월요일 아침 대표 대시보드 수치(진행률·완료 건수·게시 건수·이슈)를 집계해 보고 초안 작성 | Claude Routine(월요일 아침) | 중 | 팀장 보고 준비 시간 절감, 주간 보고 정시율 100% |
| 6 | **소요시간 월간 리포트** — 상세페이지 소요시간(h) 데이터를 월말 집계 (평균·건수·추이) | Claude Routine(월말) | 하 | 건당 2h→1h 개선의 근거 데이터, 템플릿화 대상 선정 |
| 7 | **카카오톡 문의 기록 루틴** — 문의 유형·업체를 간단 기록하는 DB (우선 수동, 추후 채널 API 연동 검토) | 노션 DB (수동) | 하 | 자주 묻는 질문 → 상세페이지·FAQ 콘텐츠 소재로 전환 |

### 온보딩 기간 특화 (7/20 ~ 7/31)
- 일일 체크리스트에 **주차별 온보딩 항목이 자동 포함**된다 (1주차: 문서 학습·SNS 계정 인수·프로세스 숙지 / 2주차: SNS 실무 투입 + 상세페이지 실습 1~2건 팀장 검수). 8월부터 자동 제거.
- 저녁 보고에 온보딩 진행 상황이 함께 집계되므로 대표·팀장이 적응 속도를 매일 확인 가능.

## 4. 자립기(3개월~, 숙련 후) 자동화 — HQ 로드맵 3단계 연결

| 자동화 | 내용 | 전제 조건 |
|---|---|---|
| 상세페이지 반자동 파이프라인 | 소요시간 데이터로 검증된 유형부터 템플릿화 → 정보 입력만으로 초안 생성 (건당 2h → 1h) | 3번 항목의 소요시간 데이터 2~3개월치 |
| 월간 콘텐츠·마케팅 계획 자동 초안 | 매달 1일, 지난달 성과(재가공 후보·저장수·문의)를 바탕으로 다음 달 발행 계획 초안 생성 → 디자이너가 검토·확정 (셀프 플래닝 전환점) | SNS 성과 기록 습관 정착 |
| 신사업 KPI 대시보드 | SLA 준수율·SNS 성장(팔로워·저장수·문의 건수)·상세페이지 처리량을 노션 대시보드로 자동 집계 | 각 DB 데이터 축적 |
| Make + Claude API (HQ 로드맵 2단계) | 매달 1일 마감 캘린더 자동 생성, 접수 시 카카오톡/메일 알림, 주간 보고 요약 | 9월~, Make 계정 |

**자립의 기준**: 디자이너가 월간 계획 초안을 스스로 확정·실행하고, 대표는 일일 슬랙 보고와 KPI 대시보드만으로 신사업을 파악할 수 있는 상태.

## 5. 도구 선택 가이드

- **노션 DB 자동화**: "DB에 무언가 생기거나 바뀌면 즉시 알림" 류. 설정 5분, 단 유료 플랜 + 노션-슬랙 연동 필요. 요약·판단은 불가.
- **Claude Routine (현재 사용 중)**: 여러 DB를 읽고 **요약·판단이 필요한 정기 보고** 류. 아침/저녁 보고, 주간 초안, 월간 리포트에 적합.
- **Make**: 노션 밖 서비스(카카오톡 알림, 메일, 쇼핑몰 플랫폼)와 연결이 필요할 때. HQ 로드맵 2단계(9월~)에서 도입 예정이므로 그 전까지는 위 둘로 충분.
