# 창립 고객 아웃리치 플레이북 — 후보 10곳 선정 + 유형별 제안 메시지

> 원칙: 50곳 무작위 발송 금지. **가능성 높은 10곳을 골라 그 업체 제품을 실제로 보고** 맞춤 2줄을 넣는다.
> 기본 메시지 골격은 `04-week1-execution-kit.md` §1. 이 문서는 선정 기준과 유형별 변형을 다룬다.

## 1. 후보 10곳 선정 워크시트

가구네닷컴 거래처·지인 업체를 아래 표에 채우고 점수 순으로 10곳 확정. (각 항목 해당 시 1점)

| 업체명 | 담당자/관계 | 제품력 있는데 사진 약함 | 신제품 자주 출시 | 온라인 판매 약함 | 상세페이지 오래됨 | 마케팅 인력 없음 | 최근 접점(3개월 내) | 점수 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | /6 |
| | | | | | | | | /6 |

**우선순위 규칙**: ① 점수 동률이면 '최근 접점 있음' 우선 (콜드보다 웜) ② 첫 3곳은 관계가 있어 피드백을 솔직히 줄 업체로 — 창립 고객의 역할은 매출보다 **사례와 데이터**다. ③ 같은 품목 직접 경쟁사 2곳에 동시 제안하지 않는다 (사례 공개 조건과 충돌).

## 2. 업체 유형별 제안 메시지 5종

공통 뼈대: 인사+관계 1줄 → **그 업체 제품 보고 쓴 맞춤 2줄** → 갈롱 시스템 소개 1줄 → 납품물 목록 → 창립가 99만원+조건 → "갈롱 전후 사례 먼저 보내드릴까요?"

### 유형 A. 제품은 좋은데 사진이 약한 제조사
> 맞춤 문장 예시:
> "[제품명]의 마감 퀄리티를 보면 이 가격대에서 흔치 않은 제품인데, 지금 사진은 그 마감이 거의 안 보이더라고요. 저희가 갈롱을 운영하며 가장 아까워하는 유형의 제품입니다."
> 강조점: 촬영비 없이 브랜드급 이미지. 소구: "공장 제품을 하루 만에 브랜드처럼".

### 유형 B. 신제품이 자주 나오는 브랜드
> "신제품이 나올 때마다 촬영 잡고 상세 만들다 보면 출시가 2~3주씩 밀리지 않으세요? 저희는 자료 받고 10영업일이면 판매 콘텐츠 일체가 나옵니다."
> 강조점: 출시 속도. 이 유형이 **구독 전환 1순위** — 첫 제안부터 "매월 신제품 대응" 언급.

### 유형 C. 오프라인·B2B는 되는데 온라인이 약한 업체
> "B2B 카탈로그는 잘 되어 있는데, 그 자료가 스마트스토어·오늘의집용 콘텐츠로는 안 바뀌어 있더라고요. 카탈로그를 온라인 판매 콘텐츠로 바꾸는 게 저희가 하는 일입니다."
> 강조점: 기존 자산 재활용 — 새로 만드는 게 아니라 갖고 있는 걸 파는 형태로 전환.

### 유형 D. 상세페이지가 오래된 브랜드
> "[제품명] 상세페이지가 [연식 추정 근거: 예 - 모바일에서 이미지가 깨져 보임/텍스트 위주]이라, 지금 유입되는 광고 트래픽이 아까운 상태로 보입니다. 상세만 바꿔도 전환이 달라집니다."
> 강조점: 이미 쓰는 광고비의 효율. 결과 보고서(체류시간·전환 변화)를 약속.

### 유형 E. 마케팅 인력을 채용하기 어려운 업체
> "마케터 한 명 연봉이면 [0,000]만원인데, 저희는 월 구독으로 콘텐츠 제작+광고 소재 개선+성과 보고까지 대신합니다. 우선 제품 1개로 시작해 보시죠."
> 강조점: 채용 대비 비용. 처음부터 구독 비교 프레임으로.

## 3. 발송·후속 시퀀스

| 시점 | 액션 |
|---|---|
| D0 | 맞춤 제안 발송 (카톡/문자 우선, 이메일 병행) + 소개서 1장 첨부 |
| D+3 | 무응답 시: 갈롱 전후 사례 이미지 2~3장만 첨부, "보시라고 보냅니다" 1회 |
| D+7 | 무응답 시 종료. 리스트에 '보류' 표시 — 갈롱 사례가 더 쌓이면 다음 분기 재접촉 |
| 응답 시 | 전화 상담 전에 **질문지 폼 먼저 발송** (04 §2) → 답변 기반 견적 초안 → 확인 후 전송 |

**금지**: 3회 이상 재발송, 가격 선할인 제시(99만원 밑으로 깎지 않는다 — 대신 창립 조건 소멸을 레버리지로), 무료 제작 제안.

## 4. 상담 → 계약 전환 스크립트 핵심 3가지

1. **가격 저항 시**: "이미지 12장 값이 아니라, 신제품 하나를 판매 가능한 상태로 만드는 값입니다. 촬영+상세 외주+광고 소재를 따로 맡기시면 [000]만원 이상입니다." (수량 비교 프레임에 들어가지 않는다 — 툴(OmniRoom류)과 비교당하는 순간 진다)
2. **AI 품질 불신 시**: 검수표(04 §4)를 그대로 보여준다. "다리 개수·봉제선·원단 색까지 이 표로 전 컷 검수하고, 통과 못 하면 폐기합니다. 저희도 가구 회사라서 제품 변형이 얼마나 치명적인지 압니다."
3. **망설임 시**: "창립 3개사가 마감되면 149만원부터 시작합니다. 지금 결정하실 필요는 없고, 갈롱 사례 보시고 이번 주 안에만 알려주세요." (기한은 진짜로 지킨다 — 창립가 연장하지 않음)

## 5. 추적 지표 (3주 차 목표 대비)

- 발송 20 → 응답 8 (40%) → 상담(질문지 회수) 5 → 유료 계약 1~2
- 응답률 20% 미만이면: 메시지가 아니라 **타깃 선정**부터 재검토 (점수표 기준 재적용)
- 상담→계약 0이면: 가격이 아니라 **사례 부족**이 원인일 확률이 높다 — 갈롱 사례 보강 먼저
